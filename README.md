# NNZ.STUDIO — портфолио (Y2K / ретро-футуризм)

Статический сайт. Без сборки, без npm, без библиотек.
Открывается двойным кликом по `index.html` или заливается на любой хостинг.

## Структура

| Файл | Что это |
|---|---|
| `index.html` | **Главный экран — ровно 100dvh, без скролла.** Телефон в центре, 8 карточек кольцом, футер-панель. |
| `archive.html` | Архив всех проектов с фильтрами по направлению. |
| `about.html` | Страница «Обо мне» — пока заглушка 404 (дизайн в работе). |
| `404.html` | Отдаётся GitHub Pages для несуществующих путей. |
| `TUNING.md` | **Карта всех визуальных значений** — для точечных правок. |

## Быстрый старт

1. Распакуй архив
2. Двойной клик по `index.html`
3. Смотри, правь, заливай

## Что менять в первую очередь

**Контакты** — `assets/js/i18n.js`, блок `CONTACTS` в конце файла:
```js
const CONTACTS = {
  behance: 'https://www.behance.net/nnzuzu5f5d',
  dprofile: 'https://dprofile.ru/nat_slatvitskaya',
  telegram: 'https://t.me/natslatvitskaya',   // ← вписать
  email: 'natslatvitskaya@gmail.com',          // ← вписать
  cv: 'https://disk.yandex.ru/'                // ← ссылка на PDF
};
```

**Проекты** — `assets/js/data.js`. Один объект = один проект.
`featured: true` → попадает в кольцо на главной (8 мест).
`cover: null` → рисуется типографическая заглушка.

**Цвета и размеры** — `assets/css/tokens.css`.

**Тексты RU/EN** — `assets/js/i18n.js`.

Полная карта значений — в `TUNING.md`.

## Что работает

- Телефон: PNG слоем, экран поверх — HTML. Парение + печать сообщений (`text me` → `hello?` → `call me` → `let's go`)
- 8 карточек кольцом, клик → модалка кейса
- Deep-link: `?project=memoria` открывает кейс сразу
- Ссылка «6 лет опыта» → `about.html`
- Теги в футере → архив с фильтром (`archive.html?filter=web`)
- Две темы: цветная / ночь, тумблер справа внизу, выбор запоминается
- RU/EN на всех страницах, запоминается
- Пасхалка: `v1.0 / console` в футере или `Ctrl/Cmd + K`

## Как править точечно

Открой `TUNING.md` — там все цифры с текущими значениями.
Формат запроса: **элемент → свойство → значение**.

Примеры:
- «карточки 160×174» → `--card-w` / `--card-h`
- «футер ниже на 30px» → `--footbar-h`
- «NAME 8 поднять на 40px» → `--oy` у `.card:nth-of-type(2)`
- «скругление карточек 16px» → `border-radius` в `.card`

Ещё быстрее: открой сайт, `F12` → Elements → покрути значение в браузере,
пришли мне получившуюся цифру. Я перенесу в код.

## Деплой на GitHub Pages

Репозиторий **публичный** → Settings → Pages → Source: `Deploy from a branch`
→ Branch: `main`, папка `/ (root)`.

В корне должны лежать: `index.html`, `archive.html`, `about.html`, `404.html`,
`assets/`, `.nojekyll`, `TUNING.md`, `README.md`.

`.nojekyll` нельзя перетащить мышкой — создай через `Add file → Create new file`,
имя `.nojekyll`, оставь пустым.

После деплоя открой с `Ctrl+Shift+R` — иначе браузер отдаст старый CSS.
